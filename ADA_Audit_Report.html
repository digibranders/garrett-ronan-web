ADA & WCAG 2.1 Audit Report | Last Updated: February 16, 2026

Target Compliance: Level AA

Executive Summary

GKR Hospitality has undertaken a significant initiative to improve web accessibility. The website has been audited against the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. Significant progress has been made, including color contrast remediation, global fluid typography implementation (12px floor), and full keyboard accessibility for all interactive sections.

Current Status: Compliant (AA)

2. Resolved Issues (Completed)

  • Skip Content Link: Added a hidden link visible on focus to bypass navigation.
  • Gallery Trap: Fixed Gallery grid to use button elements for proper keyboard support.
  • Icon Buttons: Added aria-label to Navbar toggle and Testimonial arrows.
  • Focus States: Implemented global focus rings for better visibility.
  • Floating Action Buttons: Added `aria-label="Scroll to top"` to the ScrollToTop button component.
  • Hero CTA: Updated Hero Section button text to use scalable `rem` units (14px).
  • Moving Ribbon: Updated contact ribbon background and text units for accessibility.
  • Social Links: Added `aria-label` to LinkedIn and X links in the Footer.
  • Typography Scaling: Converted all hardcoded `px` to `rem` units with a global 12px floor and fluid `clamp()` tokens.
  • Image Alt Text: Completed a global audit of all components; updated Gallery cards, About CTA, and Testimonial logos for precise descriptive compliance or decorative exclusion.
  • Interactive Sections: Remediated `What We Do` and `Process` sections to be fully keyboard accessible with `button` roles and interaction handlers.

4. Integrated Accessibility Standards

The following standards have been fully integrated into the design system and codebase. These serve as the verified baseline for current and future developments to maintain WCAG 2.1 AA Compliance.

4.1 Typography System

All font sizes must be defined in rem units relative to a 16px root. No fixed pixels (px) for text.

Element Font Family Size (rem/px) Line Height Usage
H1 Cormorant Garamond 3.5rem (56px) 1.2 Page Titles
H2 Cormorant Garamond 2.5rem (40px) 1.3 Section Headings
H3 Cormorant Garamond 1.75rem (28px) 1.4 Card/Feature Titles
Body Montserrat Fluid: 1rem - 1.125rem 1.6 Standard Paragraphs
Small/Meta Montserrat Fluid: 0.75rem - 0.875rem 1.5 Footers, Labels (12px Floor)
✅ Compliance Note: All text on the site is now strictly ≥ 0.75rem (12px). Fluid typography tokens implemented in theme.css manage the range for optimal readability.
