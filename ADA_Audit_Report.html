GKR Hospitality has undertaken a significant initiative to improve web accessibility. The website has been audited against the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. While substantial progress has been made—including keyboard navigation fixes, skip links, and ARIA labels—several items remain for Phase 2 development.

3. Remaining Action Items

B. Typography Scalability Design

Issue: Use of 10px and fixed pixels limits readability. The following areas require immediate updates:

  • Global Navigation (Navbar): Links and "Contact Us" button.
    Current: 10px  →  Desired: 0.875rem (14px)
  • Footer: Section labels and bottom bar links.
    Current: 10px  →  Desired: 0.875rem (14px)
  • Hero Section: CTA Button text.
    Current: 9px-12px  →  Desired: 0.875rem (14px)
  • What We Do Section: Card links ("View Services") and details.
    Current: 11px-12px  →  Desired: 0.875rem (14px)
  • Moving Ribbon: Contact info text.
    Current: 10px  →  Desired: 0.875rem (14px)

Fix: Update all instances to `0.875rem` (14px) minimum using `rem` units.

4. Phase 2: Design & Technical Specifications

This section serves as the definitive guide for the design and development teams for the Phase 2 update. Strict adherence to these specifications is required to ensure WCAG 2.1 AA Compliance and a premium user experience.

4.1 Typography System

All font sizes must be defined in rem units relative to a 16px root. No fixed pixels (px) for text.

Element Font Family Size (rem/px) Line Height Usage
H1 Cormorant Garamond 3.5rem (56px) 1.2 Page Titles
H2 Cormorant Garamond 2.5rem (40px) 1.3 Section Headings
H3 Cormorant Garamond 1.75rem (28px) 1.4 Card/Feature Titles
Body Montserrat 1rem (16px) 1.6 Standard Paragraphs
Small/Meta Montserrat 0.875rem (14px) 1.5 Footers, Captions (Min Size)
⚠️ Critical Rule: No text shall be smaller than 0.875rem (14px). The current 10px text in Navbar/Buttons must be updated.

4.3 UI Component Specifications

Interactive Targets

All clickable elements (Buttons, Links, Icons) must have a minimum target size.

  • Minimum Size: 44px x 44px (CSS pixels).
  • Implementation: Use CSS padding or invisible pseudo-elements to extend the hit area if the visual icon is smaller.

Focus States

Keyboard focus indicators must be strictly standardized.

/* Global Focus Style */
:focus-visible {
    outline: 2px solid #C5A059;
    outline-offset: 4px;
    border-radius: 2px;
}

Forms & Inputs

  • Input Height: Min 48px.
  • Labels: Persistent, visible labels above inputs. No placeholders as labels.
  • Error States:
    • Border turns Red (#C62828).
    • Helper text appears below input with Icon + Message.
    • aria-invalid="true" is applied.

4.4 Technical Implementation Specs

ARIA & Semantics

Usage Requirement
Icons aria-hidden="true" for decorative ions.
Icon Buttons aria-label="Action Description" (e.g., "Close Modal", "Scroll to Top").
Modals role="dialog", aria-modal="true", Focus Trap enabled (Tab key stays inside).
Images Meaningful alt text. Empty alt="" for decorative images.
